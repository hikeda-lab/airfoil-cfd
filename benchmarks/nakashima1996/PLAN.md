# 中島ら (1996) 二次元静止翼の離散周波数騒音：OpenFOAM再現計画

## 目的と原典
中島伸治・大蔦勝久・富沢正雄「二次元静止翼から発生する離散周波数騒音の研究（翼面上の境界層不安定）」日本機械学会論文集B編 62巻599号 (1996), pp.2702–2710, No.95-1470.
境界層不安定波の増幅、後縁散乱、上流への音響フィードバックを段階的に検証する。850 Hzを強制して得たピークを自励振動の再現とみなさない。既存のCLAUDE.mdに従いFoundation OpenFOAM 13、foamRun、uv、Multipassを使用する。

## 原典の条件と比較対象
- NACA0012、弦長80 mm、迎角1°、主流15 m/s、吹出口400×200 mm、乱れ度0.2%、速度偏差±1%、乱れの支配周波数32 Hz以下（図3、4.1節）。
- マイク：後縁から1 m、主流に対して90°。850 Hz卓越、425/1275/1700/2125 Hzにもピーク。OASPL 69.5 dB、暗騒音41 dB（図6、5節）。
- 仮定：nu=1.5e-5 m²/s、rho=1.225 kg/m³、c0=343 m/s。Re_c=80000、Ma=0.0437。温度等の実験値が判明すれば更新。
- 図4の排除厚さ概読値（mm）：x=65,70,75 mmで負圧面0.90,1.13,1.36、圧力面0.33,0.43,0.52。正式なデジタイズ時に更新する。原典の局所外縁速度も保存する。
- 実験波長約10 mm。下表は実験値ではなく原典Table 1/2の線形安定性解析値（850 Hz）。

## Phase 1: 2D非圧縮層流ベースライン
- 既存geometry.py/case.py/CLIを再利用し、専用ケースを生成。既存テンプレートや計算中のケースを破壊しない。
- 一様自由流の初期領域：前縁上流5c、後縁下流10c、上下各5c。後で自由噴流・ノズル・外部静止空気をモデル化し差を評価。
- Gmsh Python APIによるC型構造格子を優先し、gmshToFoamで変換。1セル厚、前後empty、翼noSlip、入口速度15 m/s・迎角1°、出口基準圧力、遠方境界は流入流出に対応。迎角の符号と負圧面を確認。
- 第一セル厚5–10 µm、40–60層、成長率1.08–1.12、翼面接線0.1–0.2 mm、後縁0.05–0.1 mm、後流0.1–0.2 mm。初期10–30万セルを目安とし、層総厚・外部格子接続・後縁品質を確認。閉後縁と有限厚後縁を比較。
- checkMesh、格子3水準、領域依存性、時間刻み依存性を確認。
- foamRun / incompressibleFluid、momentumTransport: simulationType laminar; physicalPropertiesにnu。非定常backward、移流Gauss linearを候補とし、安定性と散逸を評価。固定dt=2e-6 sを初期案とし局所Coで調整。0.3 s（15万ステップ）を目安に、短時間ベンチで実行時間を見積もる。
- x=60–80 mmの両面で2.5 mm間隔以下、壁面法線方向0–3 mm以上（外縁まで）を抽出。実験位置の0.2–3 mmを含む。局所接線速度の平均、外縁速度、排除厚さ、運動量厚さ、逆流・剥離位置を保存。
- 完了条件：図4/5の比較図、格子・時間刻み収束性、差異の説明。暫定目標は排除厚さ誤差15%以内（原典の基準ではない）。

## Phase 2: Orr–Sommerfeld線形安定性解析（Phase 1と並行）
原典式(2): (U-c)(D²-alpha²)phi - U''phi - (D²-alpha²)²phi/(i alpha Re)=0。
壁面・無限遠でphi=Dphi=0。式(4)のzeta=tanh(alpha*y/3)による変換、式(6)–(9)の差分一般化固有値問題をscipy.linalg.eigで実装。N=50–150の収束性を確認しN=125を基準とする。無限固有値・偽モードを除外し固有残差を確認。
原典式(20): U=1-exp(-1.10*y³+0.440*y²-0.0559*y)
原典式(21): U=1-exp(-0.01514*y⁵+0.201*y⁴-0.7139*y³+0.2398*y²-0.4854*y)
y=Y/delta*, U=u/Ue。原典の時間固有値法に従い、alpha=2*pi*f*delta*/(Ue*Re(c))を反復し、lambda=2*pi*delta*/alpha、G=alpha*Im(c)/(delta*Re(c))を計算。ここでRe(c)は固有値の実部でありレイノルズ数とは異なる。原典の収束条件を確認し、空間固有値法との差も必要に応じて評価。
まず原典の近似速度分布からTable 1/2を再現し、次にCFD平均速度分布を滑らかに補間してU''を評価する。図7–12を比較。暫定目標：表の波長・成長率を5%以内で再現（入力丸めの影響を記録）。

## Phase 3: 2D非定常不安定波
A: 外部周期加振なし（初期微小擾乱の有無を比較）。
B: 上流境界層に局所体積力等で850 Hz微小加振。
C: 425–3000 Hzの単周波数掃引または低振幅マルチサイン。振幅を変えて線形範囲を確認。
- 両面のx=60–80 mm、壁面法線方向に速度・圧力プローブを配置。波長推定用にはx間隔0.5–1 mm程度の追加点を設ける。
- G=d ln A/dx、lambda=2*pi*dx/abs(delta_phase)。クロススペクトル、位相アンラップ、コヒーレンス、局所位相速度を評価。原典の熱線測定に対応する速度変動の定義・位相基準も再現する。
- 初期過渡を除外し、等間隔サンプリング（例10 µs以下）、解析窓0.1–0.2 s以上。Welchの窓長・分解能・振幅規約を記録。
- 完了条件：増幅帯域、波長、成長率、振幅・位相分布を原典と比較。強制応答と自然発振は区別する。

## Phase 4: 3D LES
- スパン10/20/40 mm、cyclic、WALE（壁面解像を目標）、スパン刻み0.2–0.4 mmを初期案とする。y+、接線・スパン解像度、SGS粘性、解像エネルギーを確認。
- 2D全領域の単純押し出しはメモリ負荷が大きいため、局所細分化・粗い試験ケースから開始。200万セル程度を最初の予算目標とするが、実測メモリで判断。解像度を犠牲にして本番としない。
- スパン方向の壁面圧力相関、コヒーレンス、渦構造、2Dとの差を評価。幅の収束を確認。

## Phase 5: Curle / FW-H
既存src/airfoil_cfd/acoustics.pyを拡張。静止剛体のLoading noiseを第一対象とし、厚み項は静止不透過面でゼロ。体積四重極項を無視する近似の限界を記録。
- 面素ID、中心、外向き法線、面積、壁面圧力時系列を固定メッシュで保存。運動学的圧力はrho倍でPaに明示変換。振幅による単位推定を廃止。
- 遅延時刻を補間し、全音源が有効な共通時間区間を使用。時間微分と符号を解析解で検証。非コンパクト音源として各面の距離を使用（850 Hzでkc≈1.25）。
- Curleの遠方場項に加え、必要に応じ近接場項を含む静止面FW-H Loading式を実装。両者の一致を単体テスト。
- 既知の正弦双極子、距離減衰、指向性、位相遅延、Pa換算、PSD積分とRMSの一致をテスト。可変dtは明示的に再サンプル。再開時のprobeファイルを数値時刻順に結合し重複除去。
- 1 m・90°の観測点でSPL、OASPL、ピーク群を比較。69.5 dBは約0.0597 Pa rms。実験の帯域幅不明の場合は絶対比較の制約を記載。2D単位スパンから全翼への換算は完全相関と有限相関を区別し、実効スパンが不明なら絶対SPLを確定しない。
- 非圧縮probe圧力のFFTは流体圧力変動であり放射音ではない。後処理FW-H/Curleは音響フィードバックを生成しない。

## Phase 6: 音響フィードバックの再現
- OF13 compressibleFluidを候補とし、利用可能な熱物性・境界条件を公式チュートリアルとfoamInfoで確認。低Maでの音波伝播を一様流中の微小音波テストで検証する。
- 非反射境界、スポンジ層、領域サイズの感度を評価。音響Courant数と位相誤差でdtを決める。50 µmセルの音響通過時間は約0.146 µs（陰解法でも精度検証が必要）。
- まず2Dで無加振の自励発振、後縁から上流への音波、ループ位相・増幅を検証。2Dの放射減衰は3Dと異なるため絶対SPLは別途評価。
- 計算資源が不足する場合は非圧縮CFDと線形音響・受容性モデルの双方向連成を代替研究案とする。単なる一方向後処理とは区別する。

## Claude Codeへの作業順序
1. 原典の表・式を転記して検証用CSVと条件YAMLを作成。図の概読値には出典と不確かさを付記。
2. stability.pyと単体テストを作成しTable 1/2を比較。
3. C型格子生成とcheckMeshを自動化し短時間2D層流ケースを実行。
4. 境界層抽出・比較図、格子/時間刻み感度を実施。
5. Phase 3以降は前段の結果をレビューしてから開始。計算中の既存ジョブを停止しない。
各段階でコマンド、結果、失敗、未解決事項をREADMEに記録。6週間は初期開発の目安であり、3D・圧縮性本計算の完了を保証しない。数値設定・許容誤差は提案値であり、実験条件と区別する。
